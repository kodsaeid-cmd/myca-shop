# اصلاح یکپارچه پنل مدیریت و صفحه اصلی — MYCA Shop

**محیط هدف:** `shop.mycablog.dandoonii.ir` روی cPanel پارس‌پک  
**نیاز به Migration جدید:** خیر. هیچ تغییری در دیتابیس ایجاد نمی‌شود.  
**نوع تغییر:** اصلاح کد صفحه اصلی، یکی‌کردن پنل قدیم و جدید، حفظ API و طراحی قبلی.

## قبل از نصب

1. از پوشه کامل فروشگاه و دیتابیس مستقل فروشگاه نسخه پشتیبان بگیرید.
2. در cPanel > File Manager وارد پوشه اختصاصی `shop.mycablog.dandoonii.ir` شوید. به پوشه مجله مایکا دست نزنید.
3. هر فایل موجودی که قرار است جایگزین شود را موقتاً به نسخه پشتیبان کپی کنید؛ مخصوصاً `admin/index.php`، `admin/commerce.php`، `assets/platform-admin.js` و `index.php`.

## فایل‌هایی که باید جایگزین شوند

فایل‌های بسته را با **همان ساختار پوشه‌ها** در ریشه فروشگاه استخراج کنید:

- `index.php` ← صفحه اصلی فروشگاه؛ حالا مستقیماً ویترین سروری CMS / کاتالوگ را نمایش می‌دهد و به `index.html` وابسته نیست.
- `admin/index.php` ← **ورودی واحد پنل ادمین**: فرم ورود + داشبورد، مدیریت محصولات، دسته‌بندی‌ها و تمام بخش‌های تجارت.
- `admin/commerce.php` ← لینک قدیمی را به `/admin/` هدایت می‌کند؛ پنل دوم مستقل وجود ندارد.
- `admin/.htaccess` ← تنظیم `DirectoryIndex index.php` برای آدرس `/admin/`.
- `assets/platform-admin.js` ← رابط یکپارچه به APIهای فعلی متصل است و شامل CRUD محصول/دسته و آپلود تصویر است.

**لازم نیست** `api/`، `app/config.local.php`، `db/`، پوشه `uploads/` یا فایل‌های مجله جایگزین شوند.

## اگر آدرس اصلی فروشگاه با وجود `/index.php` باز نشد

فایل `.htaccess` **موجود در ریشه پوشه فروشگاه** را باز کنید و فقط این خط را **با حفظ بقیه قوانین** قرار بدهید:

```apache
DirectoryIndex index.php index.html
```

فایل `.htaccess` ریشه را از هیچ ZIP جایگزین نکنید. سطح دسترسی معمول پوشه‌ها `0755` و فایل‌های قابل سرو `0644` است. `app/config.local.php` محرمانه بماند.

## مسیرهای تست

- `https://shop.mycablog.dandoonii.ir/index.php` — صفحه اصلی PHP مستقل از `index.html`
- `https://shop.mycablog.dandoonii.ir/` — صفحه اصلی با DirectoryIndex صحیح
- `https://shop.mycablog.dandoonii.ir/storefront.php` — پیش‌نمایش ویترین CMS
- `https://shop.mycablog.dandoonii.ir/admin/` — **تنها ورودی مدیریت**
- `https://shop.mycablog.dandoonii.ir/admin/commerce.php` — هدایت به مسیر بالا
- `https://shop.mycablog.dandoonii.ir/assets/platform-admin.js?v=5` — باید JS را نمایش دهد، نه 403/404
- `https://shop.mycablog.dandoonii.ir/api/catalog.php` — باید `ok:true` برگرداند

پس از آپلود از `Ctrl+F5` استفاده کنید. اگر پنل خطای «API» نمایش داد، بدون افشای رمز از Console/Network تصویر بگیرید.

## امنیت

این محیط آزمایشی هنوز گواهی HTTPS مورد اعتماد مرورگر ندارد. **تا قبل از اصلاح SSL نباید رمز واقعی مدیریت، اطلاعات شخصی مشتری، نشانی یا پرداخت را در آن وارد کرد.** ثبت سفارش و پرداخت واقعی همچنان فعال نیست. از حساب آزمایشی بی‌ارزش استفاده کنید؛ پس از پایان تست حساب را غیرفعال و رمز افشاشده دیتابیس را تعویض کنید. فایل تشخیص اتصال قدیمی را حذف کنید.

## بازگشت

کدهای جایگزین‌شده را با نسخه‌های پشتیبان مرحله قبل بازگردانید. هیچ تغییر دیتابیسی در این اصلاح نیاز به Rollback ندارد.
